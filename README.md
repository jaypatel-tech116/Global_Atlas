# 🌍 Country Info Explorer

> A modern, responsive React web application to explore detailed information about every country on Earth — flags, populations, capitals, languages, currencies, and bordering countries.

## ✨ Features

- **🌐 Global Country Grid** — Beautifully designed card layout showing flags and key details for every country.
- **🔍 Real-time Search** — Instantly filter countries by name as you type.
- **🗂 Region Filter** — Filter by Africa, Americas, Asia, Europe, or Oceania in one click.
- **📄 Pagination** — Smooth, efficient pagination to navigate 250+ countries without lag.
- **🧾 Detailed View** — Native names, TLDs, subregions, currencies, languages, and bordering countries.
- **📱 Fully Responsive** — Optimised for mobile, tablet, and desktop.
- **⚡ Fast & Modern** — Built with Vite and React 19's `useTransition` for a lightning-fast UI.

## 💻 Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed.

### Installation

**1. Clone the repository**
```bash
git clone https://github.com/jaypatel-tech116/Global_Atlas.git
cd React_Final_Project_Country_Info
```

**2. Install dependencies**
```bash
npm install
```

**3. Start the development server**
```bash
npm run dev
```

**4. Open in your browser**
http://localhost:5173
